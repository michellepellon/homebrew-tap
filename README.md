# Homebrew Tap

Homebrew formulae for my tools.

## Installation

```bash
brew tap michellepellon/tap
```

## Available Formulae

### feedback

A modern TUI podcast client for the terminal.

```bash
brew install michellepellon/tap/feedback
```

Or after tapping:

```bash
brew install feedback
```

## Requirements

`feedback` requires either VLC or mpv for audio playback:

```bash
brew install vlc
# or
brew install mpv
```
